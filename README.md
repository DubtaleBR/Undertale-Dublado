DubtaleBR - UNDERTALE Dublado em PT-BR

DubtaleBR é um projeto gratuito e não oficial de tradução e dublagem brasileira de UNDERTALE.

Versão 0.1

- Requisitos
UNDERTALE original para Windows, versão 1.08.
Delta Patcher.

- Download

Acesse a seção Releases e baixe o arquivo DubtaleBR_Demo_01.zip.

As instruções completas de instalação e os créditos estão incluídos no download.

- Canal do projeto

https://www.youtube.com/@DubtaleBR

Aviso

O jogo original não está incluído. Este projeto não possui afiliação com Toby Fox, a equipe de UNDERTALE ou a Steam. UNDERTALE e seus elementos originais pertencem aos respectivos detentores de direitos.
