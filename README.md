# UNDERTALE Dublado PT-BR

**UNDERTALE Dublado PT-BR** é um projeto gratuito e não oficial de tradução e dublagem brasileira de UNDERTALE, produzido pelo grupo **DubtaleBR**.

## Versão 0.1

Esta é a primeira versão pública do projeto. O conteúdo atual vai do início do jogo até o final das Ruínas.

## Requisitos

- Uma cópia original de UNDERTALE para Windows, versão 1.08.
- Delta Patcher.

## Download e instalação

Acesse a seção [Releases](https://github.com/DubtaleBR/Undertale-Dublado/releases/latest) e baixe o arquivo `DubtaleBR_Demo_01.zip`.

Depois de extrair o arquivo, siga as instruções presentes no `INSTALAÇÃO.txt`.

## Canal do projeto

[DubtaleBR no YouTube](https://www.youtube.com/@DubtaleBR)

## Aviso

O jogo original não está incluído. Este projeto não possui afiliação com Toby Fox, a equipe de UNDERTALE ou a Steam. UNDERTALE e seus elementos originais pertencem aos respectivos detentores de direitos.
